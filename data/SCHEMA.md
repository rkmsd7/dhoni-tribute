# Data layer

Edit the JSON, not the JS. Every page reads only from this folder.

| File | Used by | Shape |
|---|---|---|
| site.json | all pages | name, title, tagline, subtitle, occasion, dates, nav[], stats[] (hero strip), phrases[], dataNote |
| timeline.json | / | eras[{id,title,years,summary}], events[{id,era,date,title,place,text,tags[],source,media?}] |
| images.json | /, gallery, moments, man | [{id,src(1280px),full,w,h,caption,alt,date,author,license,source,era,tags[],hero?}] |
| videos.json | videos | [{id,youtube,title,channel,note,era,tags[],playlist}] |
| quotes.json | /, man | [{text,source}] |
| matches.json | matches, stats | generated by the Cricsheet build script; one object per match (see Every match page) |
| stats_computed.json | stats, captaincy, keeping, ipl | generated aggregates: meta.coverage, byFormat, byYear, byOpponent, byCountry, captaincy, chasing, battingPosition, topInnings, topKeeping, bowling |
| replays.json | moments | generated ball-by-ball for selected matches: innings[{team,target,total,deliveries[],overTotals[]}], dhoniInnings[] |
| records.json | records, stats | official{formats[],international}, records[{title,value,kind,context,stands,source,sourceUrl}], milestones[], verification[] |
| captaincy.json | captaincy | intro, summary[], iccTournaments[], otherTrophies[], testSeries[], pillars[], scenarios[] (decision lab), quotes[] |
| keeping.json | keeping | intro, totals[], comparison{keepers[]}, skills[], famous[], sources[] |
| ipl.json | ipl | intro, career{}, seasons[], seasonNote, csk[], rivals[] |
| moments.json | moments | intro, matches[{id,date,title,subtitle,venue,format,result,replay?,story[],stat,quote?,source}] |
| trophies.json | trophies | intro, international[], franchise[], finalsAsCaptain[] |
| man.json | man, / | intro, sections[{id,title,text[],quote?,source?}], awards[], legacy[], closing |

Generated files come from `scripts/build.py <cricsheet-dir> <out-dir>` (kept outside the repo); re-run after new Cricsheet releases.
